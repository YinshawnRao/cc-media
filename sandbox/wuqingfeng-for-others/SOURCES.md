## 构建流水线（可复现）
1. `build/clips.sh` — 输出端seek切展示段 + 前景调色 + `vfill.sh`竖屏化(裁烧字/水印/黑边) → `clips_seg/<key>.mp4` + `audio/<key>_music.wav`。
2. `build/narrate_segments.py`(venv) → `audio/<key>.wav` + `narration.json`（女声 zf_xiaoyi）。
3. `build/full_build.py` → `master.wav`(逐首 床→swell→展示, loudnorm I=-14) + `hf/index.html`(#5→#1揭晓卡+每首主题色+真人封面) + 拷资源。
4. 渲染 `npx hyperframes render --sdr` → mux master.wav。
