# design.md — 林夕给王菲写的歌，10首最封神（竖屏长片）

风格关键词：高级 · 克制 · 文艺 · 精神性 · 港风文学。**不要榜单综艺花字。**

## 画幅 / 帧率
- 1080×1920 竖屏，30fps，H.264 + AAC。render 必加 `--sdr`。
- 成片以 mux 后为准（HyperFrames 压平音频动态 → 后期 mux master.wav）。

## 配色（暗底 + 单一强调色：暗红）
- 底：`#08080b` / `#0b0a0e`（近黑，略带冷调）
- 主文字：米白 `#ece4d6` / `#e7ddca`
- 强调色（唯一）：暗红 `#8c2026` / 亮一档 `#b4373b` / 暗 `#5e161a`
- 次要：灰蓝 `#465a6e` / `#5b6e80`（资料/装饰），暖纸色 `#cdbfa6`（手写歌词纸）
- 颗粒 / 暗角 / 微光叠层全程压住，宁暗勿亮。

## 字体（Google Fonts，HF 自动 fetch）
- 中文衬线主标 / 旁白字幕：**Noto Serif SC**（500/600/700/900）
- 西文优雅 / 装饰短语 / 年份：**Cormorant Garamond** italic（400/500）
- 中文无衬线 UI / 资料字幕 / 标签：**Noto Sans SC**（400/500/700）
- 数字 / 番号 / 年份 mono：**JetBrains Mono**
- 手写歌词纸碎片：**Ma Shan Zheng**（毛笔楷书，仅极少量关键词，绝不整段铺）

## 画面语言
- **主体 footage（王菲 MV/Live）一律 letterbox**：缩到 1080 宽居中、保留原比例，上下留黑（电影感 cinemascope 条）。**禁止竖裁放大**（双人/合唱/宽机位会切人）。只裁烧死歌词的横向窄带。
- **氛围 footage（城市夜景 / 老唱片 / 空镜）可全幅 cover** 当暗背景（无主体需保护），压暗 + 颗粒。
- 全程叠：film grain（SVG turbulence 静态纹理 + 轻微位移/闪烁）、径向暗角 vignette、极淡光晕。
- 转场：慢叠化（cross-dissolve 0.8–1.2s）、黑场呼吸。**不快闪、不滑屏花字。**
- 意象层：暗红花（彼岸花/玫瑰，SVG/渐变）、老唱片旋转、歌词纸、城市夜景、信、钟、月——按每首主题选。

## 结构（全片 10→1，本期先做样片）
样片 = 封面 + 开头(8s+) + 第10首《人间》。通过后批量其余 9 首。
- **封面**：主标「林夕把王菲写成了神」/ 副标「10首封神词作盘点」。王菲冷感主图 + 林夕手稿/歌词纸/旧唱片/暗红花/黑白胶片拼贴。**元素居中**（小红书3:4安全区 y240–1680），不泄漏歌单。
- **每首**：① 番号+歌名 ② 资料字幕(词林夕·唱王菲·专辑年份) ③ 意象空镜进入 ④ 旁白点评(音乐 duck) ⑤ 连续副歌展示 ≥25s(音乐全量、无旁白) ⑥ 主题转场句递进。
- 每首主题标签：人间/相思/时间/暗涌/命运/错过/自爱/孤寂/盛放/彼岸。

## 音频（硬规则）
- 先配音后进音乐；旁白期音乐压到床位（约 -12-- -14dB / 25%），300ms 平滑；旁白收尾留 0.8–1.2s 消化位再 swell。
- 展示段音乐全量、无旁白，连续副歌 ≥25s。
- 各首副歌响度统一 loudnorm I=-14（落 ~-15dB）。
- **零容忍背景白噪音**：不用全片 ambient pad 兜底；段间用对应歌曲极低音量做床/桥接，或接受 <1.5s 自然短静音。

## 选源（硬约束）
- 两边都找（YouTube + B站），按清晰度/干净度/立体声/版本质量挑。展示段优先官方MV > 官方Live > 综艺Live。
- 成片画面不得出现水印/网址/提示词/路径/项目内部词，也不打"制作机制/救场声明"meta 文案。
- 封面真人本人头像（可从其 MV/Live 抽帧），裁净烧字水印。
