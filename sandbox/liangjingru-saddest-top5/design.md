# 梁静茹最苦的5首歌 — Design

## Format
- 竖屏 1080×1920，30fps，全长约 4:58。
- 倒数盘点：第5名 → 第1名。
- 开头**不公布**排名（封面 = 标题 + 作品描述）；片尾揭晓完整榜单。
- 每首结构：女声解说（音乐床）→ 消化位/swell → 连续副歌展示（现场原声全量）。
- 配音：女声 `zf_xiaoyi`（Kokoro + misaki[zh]）。

## Visual Identity（心碎 / 克制）
- 基调：暗夜、克制、情绪向；不是综艺花字，是安静的疼。
- 背景：本人现场 footage，默认 letterbox 保原比例；只有《会过去的》街头单主体竖向放大。
- Palette：
  - base `#08070c`
  - text `#f6f0f1` / muted `#cfc4c8`
  - accent 玫瑰 `#e89aa6`（眉标、序号、卡片左边、tag）
  - 强调玫瑰 `#f1a9b4` / `#f3b6bf`
  - rank-1 危机红 `#ff5566 / #ff7882`
- Type（衬线提质感，参考 dou-family 经验）：
  - 歌名 / 大标题：**Noto Serif SC** 700–900
  - 解说 / UI：**Noto Sans SC** 400–700
- Motion：干净的位移/淡入，封面标题轻微 breathing；无装饰性光球。

## Composition Rules
- 封面：标题 + 作品描述，**不列五首歌名**；首帧即可作缩略图（本人《崇拜》白西装情绪特写 letterbox 居中）。
- 歌曲卡：大号「第 0X 名」+ 年份 + 歌名（serif）+ tag + note；展示段只留左上角小排名标签，让画面呼吸。
- 字幕只表达当下解说意思；画面内无水印/网址/路径/项目内部词。
- 片尾榜单：1 会呼吸的痛 · 2 可惜不是你 · 3 慢冷 · 4 崇拜 · 5 会过去的。

## 节奏 / 时长
- 展示段（连续副歌）：第5–2名 ≈ 34s，第1名压轴 ≈ 40s。
- 解说约 14–16s/首，解说期音乐为低床，副歌展示全量、无旁白。
