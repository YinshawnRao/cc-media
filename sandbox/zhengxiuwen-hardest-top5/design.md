# 郑秀文最难的5首歌 — Design

## Format
- Vertical 1080×1920, 30fps. Countdown 5 → 1.
- Cover = title + premise only; **no ranking list** (用户要求留悬念).
- Each song: female narration (music bed) → digest beat → continuous ~38s chorus showcase (footage 窗 == 音乐窗).
- Ending: 作品 outro (ranking summary + theme) → 1.0s digest → fixed CTA (last line).

## Visual identity
- Mood: restrained, premium, "百变天后" — quick-song power meets ballad control.
- Background: real MV/Live footage, letterboxed (subtitle/watermark cropped, original ratio kept).
- Palette: base `#08070b`; text `#f7f3ee`; muted `#cfc6ba`; accent champagne-gold `#e6b07a`; rank-1 diva rose `#ff5c8a / #ff79a3`.
- Type: heavy CJK display weights, no negative tracking. Gold eyebrow rule + chips.
- Motion: clean slides + fades only; no decorative orbs.

## Composition rules
- Song card (bottom-left bar): 第 N 名 / 歌名 / tag / note. Rank-1 switches accent to rose.
- Showcase keeps only a small top-left rank tag so footage breathes.
- No burned lyrics / platform / UP / URL / path / meta text anywhere in frame.
- Final summary (1→5): 01 煞科, 02 终身美丽, 03 值得, 04 不要惊动爱情, 05 默契.
- CTA overlay (synced to fixed CTA audio): "你最想为哪一首？评论区投票" + 点赞·收藏·关注.
