# 梁咏琪最难的5首歌 — Design

## Format
- Vertical 1080×1920, 30fps. Countdown 5 → 1. Female voice (`zf_xiaoyi`) throughout.
- Cover = title + premise only; **no ranking list** (用户要求留悬念，开头不暴露排名).
- Each song: female narration (music bed) → digest beat → continuous ~34s chorus showcase (footage 窗 == 音乐窗, lip-sync).
- Ending: 作品 outro (ranking summary 5→1 + theme) → 1.0s digest → fixed CTA (last line, 逐字照念).

## Visual identity
- Mood: clean, premium, "高妹" — bright clear voice, the control hidden under songs that sound effortless.
- Background: real Studio-Live / MV footage, letterboxed (logo/lyric/watermark cropped as full-width bands, original ratio kept, no zoom-crop).
- Palette: base `#07080c`; text `#f6f4ef`; muted `#ddd6ca`; accent champagne-gold `#e6b07a` (complements the green-suit footage); rank-1 heartbreak rose `#ff5c8a / #ff79a3`.
- Type: heavy CJK display weights, no negative tracking. Gold eyebrow rule + chips. Title shadow for legibility over footage.
- Motion: clean slides + fades only; cover h1 subtle breathing; no decorative orbs.

## Composition rules
- Song card (bottom-left bar): 第 N 名 / 歌名 / tag / note. Rank-1 switches accent to rose.
- Showcase keeps only a small top-left rank tag so footage breathes.
- No burned lyrics / platform / UP / URL / path / meta text anywhere in frame (cropped + verified per-edge).
- Final summary (1→5): 01 原来爱情这么伤, 02 花火, 03 烟雾弥漫, 04 嫌弃, 05 高妹正传.
- CTA overlay (synced to fixed CTA audio): "你最想为哪一首投票？" + 点赞·收藏·关注. Outro itself carries NO vote question (anti double-CTA).

## Pacing
- intro ~17.9s, 5 songs × (~19s narration + 1.5s digest + 34s showcase ≈ 54s), outro+CTA ~32s. Total ≈ 5:16.
