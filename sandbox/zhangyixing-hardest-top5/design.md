# design.md — 张艺兴最难的5首歌

## 基调
唱跳歌手"高难度舞台"主题，比抒情向盘点更需要**力量感 / 节奏感 / 舞台光效**，但仍保持"干净高级、暗底 + 单一强调色"的系列统一底线，不做综艺花字。

## 配色
- 底色：近黑 `#07080d`（与系列其余项目一致，跨期风格统一）。
- 强调色：**电光蓝紫 `#8f7bff`**（区别于系列常用的雾蓝 `#a8c2ea`，贴合"国风+说唱+舞台"更冷冽/更有张力的气质）。
- 压轴（#1《莲》）专属强调色：**暖金 `#e8c977`**（沿用系列"公认天花板"角标惯例）。

## 字体
- 中文黑体：`PingFang SC`（标签/正文）。
- 中文衬线：`Songti SC`（歌名大字，保留系列辨识度）。
- 等宽：`JetBrains Mono`（排名数字/序号）。

## 版式
沿用 `zhangbichen-hardest-top5` / `xuruyun-underrated-top5` 已验证的版式骨架：
- 封面：eyebrow + 大字标题 + 简介 + 关键词 chips。
- 每首：fullLabel（排名+meta+歌名+tag+note）→ mini 常驻角标（展示段淡出大标签、保留精简角标，见通用规则「信息层级去重」）。
- 转场：轻量竖向扫光条（`.trans`），比系列默认略提高透明度峰值以贴合"舞台感"。
- outro：终榜单列表 + 主题升华，固定 CTA 收尾。

## 动效
GSAP 默认缓动集（power2/power3/sine），封面呼吸缩放。转场扫光条时长与系列一致（0.9s）。不引入额外粒子/AE 形变（渲染成本 + brief 未要求）。

## 展示段策略
张艺兴的曲目多为**编舞强度大**的官方 MV/舞台版，单主体全程在场概率高 → 优先 letterbox 全宽（默认），若某曲源经抽帧确认全程稳定居中单人特写，才考虑竖裁放大（需逐帧验证，见 CONVENTIONS 展示段硬规则 A）。
