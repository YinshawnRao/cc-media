# 陈慧琳最难的5首歌 — Design

## Format
- 竖屏 1080×1920，30fps，总时长 ~5:40。
- 倒数揭晓：第5 → 第1。
- 开头只有封面 + 选题描述，**不剧透完整排名**；片尾再一次性列出榜单。
- 每首结构：女声介绍旁白（音乐床）→ 消化位/swell → 连续副歌展示（音乐全量，每首 38s）。
- 配音：女声 `zf_xiaoyi`（brief 指定女声）。
- 结尾固定引流 CTA（全片最后一句，照念，见 CONVENTIONS「固定结尾配音」）。

## Visual Identity（沿用系列暗金基调，契合千禧天后）
- 基调：声乐难度盘点，经典天后，克制有戏剧感。
- 背景：真实 MV footage，letterbox 保原比例（除非裁切框逐帧确认安全）。
- 配色：
  - base `#08070a`
  - 面板/scrim `rgba(5,5,8,.70)`
  - 正文 `#f8f3ec`，次要 `#cec4b8`
  - 强调金 `#d6b16a`
  - 第1名危险红 `#c7333f` / `#ff727d`
- 字体：系统 CJK 粗体，无负字距；短视频字号放大基线。
- 动效：干净滑入、压力线揭示、细噪点，无装饰球/光斑。

## Composition Rules
- 封面：标题 + 作品描述，不列五首歌。
- 每首大号倒数序号 + 歌名 + 一句难点标签 + 一句注释；展示段只留左上角小序号条让画面呼吸。
- 烧死歌词的源已在 footage 阶段全宽裁掉（不靠 mask）。
- 字幕/标签只显示当前旁白意思，不出现任何内部制作说明、平台/UP水印、网址、路径。
- 片尾榜单：1 花花宇宙 / 2 失忆周末 / 3 不如跳舞 / 4 大日子 / 5 谁愿放手。
- 防双 CTA：作品 outro 只做内容总结 + 主题升华，不带投票问句；互动 ask 交给固定结尾句。
