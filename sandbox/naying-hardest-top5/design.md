# 那英最难的5首歌 — Design

## Format

- Vertical short-form video, `1080x1920`, 30fps.
- Countdown order: 5 -> 1.
- Opening must show only cover + premise, not the full ranking.
- Each song section: female narration -> short breathing beat -> continuous chorus/showcase.
- Ending can reveal the full ranking summary.

## Visual Identity

- Mood: high-pressure vocal analysis, classic diva, restrained and dramatic.
- Background: real MV/live footage, letterboxed unless a crop is proven safe.
- Palette:
  - base: `#08070a`
  - panel/scrim: `rgba(5,5,8,.70)`
  - text: `#f8f3ec`
  - muted text: `#bdb3a6`
  - accent: `#d6b16a`
  - danger accent for rank 1: `#c7333f`
- Type: system CJK stack, heavy display weights, no negative letter spacing.
- Motion: clean slide-ins, pressure-line reveals, subtle grain, no decorative blobs/orbs.

## Composition Rules

- Cover: title + work description only, no list of five songs.
- Song cards use large countdown number and song title, but do not over-cover the singer.
- Showcase sections keep only a small top-left rank tag so the music footage can breathe.
- KTV lyric sources use a bottom mask in final composition; mask must sit below labels and hide the burned lyric area.
- Captions/labels show only the current narration idea, never internal production notes.
- Final summary lists: 1 征服, 2 默, 3 白天不懂夜的黑, 4 出卖, 5 不管有多苦.
