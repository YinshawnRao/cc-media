# 林忆莲最被低估的5首歌 — Design

## Format

- Vertical short-form video, `1080x1920`, 30fps.
- Narrated countdown 5 -> 1. Female voice (`zf_xiaoyi`).
- Opening shows only cover + work description, NOT the ranking list (keep suspense).
- Each song section: female narration -> short breathing beat -> continuous chorus/showcase (>=~30s).
- Ending reveals the full 5->1 ranking summary, then the fixed CTA last.

## Visual Identity

- Mood: restrained, literary, dusk/dawn melancholy — Sandy Lam's urban-poetic, "high-class restraint".
- Background: real MV/live footage, letterboxed unless a crop is proven frame-safe.
- Palette (softer / cooler than the diva-red naying set, to match 留白/疏离):
  - base: `#0a0910`
  - panel/scrim: `rgba(8,8,14,.70)`
  - text: `#f4eee6`
  - muted text: `#c2bccb`
  - accent: `#c8a2d8` (muted lilac — nods to 野花/太阳系 dreamy register)
  - rank-1 accent: `#e8c170` (warm gold — the crown gem 没有发生的爱情)
- Type: system CJK stack, heavy display weights, no negative letter spacing.
- Motion: clean slide-ins, soft grain, no decorative blobs.

## Composition Rules

- Cover: title + work description only, no list of five songs.
- Song cards: large countdown number + song title + album/year + one-line angle; do not over-cover the singer.
- Showcase sections keep only a small top-left rank tag so footage breathes.
- KTV/burned-lyric sources get a bottom mask; mask sits below labels and hides the lyric band.
- Captions/labels show only the current narration idea, never internal production notes.
- No watermark / URL / platform ID / path / prompt anywhere on screen.
- Final summary lists 5->1: 5 太阳系, 4 理由, 3 我坐在这里, 2 飞的理由, 1 没有发生的爱情.
- Outro elevates on theme only (no vote ask — the fixed CTA owns the互动).
