## 设计 / 制作
- 结构：封面(真人脸) → intro 旁白 → 5×(暗底**揭晓卡**：巨幅 ghost 名次 + 歌名/专辑/标签，旁白铺垫 → 音乐 swell 推满、**特写画面 reveal** 展示副歌) → outro 总榜升华 → **固定引流 CTA**（全片最后一句，硬约束，brief 不覆盖）。
- 封面真人脸取自《谁》Legacy 特写帧（满足真人封面硬约束）。
- 配色：深墨底 + 暖琥珀强调色 + 第一名金色；衬线 Noto Serif SC 标题/名次，无衬线 Noto Sans SC UI。
- 混音：逐首 `loudnorm I=-14` + 每首微调 mgain，5 段展示副歌统一到 **−15.0~−15.2 dB**（实测）；旁白段音乐 duck 到 ~−21 dB（差 ~6–8 dB）；全片无 >1s 静音。HyperFrames 渲染压平动态 → 成片用预混 master.wav **后期 mux**。
- 渲染：1080×1920、`--sdr`、`-w1` + 重试（本机 GPU 截帧偶发崩）。
- 展示段 mp3 供耳审：`qa/showcase/sc_*.mp3`（尤其 #4《失乐园》摇滚曲，vocal 检测对满编曲不可靠，请耳核确为“在唱”的副歌）。
