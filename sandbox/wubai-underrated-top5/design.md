# 伍佰最被低估的5首歌 — Design

## Format
- 竖屏短视频 1080×1920, 30fps。
- 倒数盘点 5 → 1。**片头只给封面+作品描述，不剧透名次**；片尾完整列榜。
- 每首结构：女声解说旁白（音乐床）→ 消化位 → swell → 连续副歌展示（SHOW≈29s）。
- 配音：女声 `zf_xiaoyi`（Kokoro），文案据用户描述打磨成自然口播。

## 主题与基调
- 主题：被低估的「专辑遗珠」——怀旧、温柔、后劲，而非技术炫技。
- 背景：真实 MV/官方Live footage，letterbox 保原比例（4:3 源裁底部烧词后信箱式呈现）。
- 调色：暗底 + 暖琥珀强调色，怀旧。
  - base `#08070a`、panel `rgba(6,5,9,.6)`、text `#f6f1ea`、muted `#cdc4b9`
  - accent 琥珀 `#e8b96a`、压轴(第1名)危险色 `#ef4d5a`
- 字体：Noto Sans SC（HF compile 自动拉取），系统 CJK 兜底。
- 动效：干净滑入、无装饰光球。封面首帧即完整（不给封面 fade-in，符合首屏封面硬约束），靠背景footage运动+轻微呼吸提供动感。

## 构图规则
- 封面：标题 + 作品描述 + 5 个气质标签（专辑遗珠/越听越上头/被低估的温柔/真爱粉认证/后劲很大），**不列歌名、不剧透名次**。
- 歌曲卡（fullLabel）：大号「第 N 名」+ 歌名 + 一句点评(tag) + 专辑背景(note)，左下，不长期遮挡画面。
- 展示段：只留左上角小角标（序号+歌名），让 footage 呼吸。
- 片尾：完整榜单 1→5（第1名红色角标）。

## 混音
- 旁白响起音乐降到床(BED=0.15)，swell 升起，副歌全量；逐首 `loudnorm=I=-14` 统一，目标副歌 ~-15.7dB。
- HyperFrames 只渲画面；预混 master.wav 后期 mux 覆盖音轨。
- **展示段必须有人声**：救场曲音频窗用 `tools/video/vocal_segments.py` 选有唱的段（来不及 chorus=89s 中段演唱、破碎 chorus=24s 开头主歌）——别按 RMS 响度选，满编曲的响度峰常是吉他 solo/outro（来不及185s/破碎275s 实测无人声，已弃）。

## 固定结尾 CTA（铁律⑥）
作品 outro（列榜+主题升华，不带投票问句防双CTA）→1s消化位→**固定引流句**（全片最后一句，逐字照念）"你最想为哪一首投票？评论区告诉我。记得点赞、收藏、关注我，下一期，可能就盘到你单曲循环过的那一首。"→末1.8s淡出。配 CTA 浮层（投票/点赞/收藏/关注，无平台水印/账号/网址）。见 CONVENTIONS「固定结尾配音」。
