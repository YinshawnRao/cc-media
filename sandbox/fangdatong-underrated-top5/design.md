# 方大同最被低估的5首歌 — Design

## Format
- Vertical short-form, `1080x1920`, 30fps.
- Countdown order **5 → 1**. Opening does NOT reveal the ranking list (cover = title + premise only).
- Each song: female narration (over music bed) → short swell → continuous chorus showcase (~38s).
- Outro reveals the full ranking list.

## Hard constraints from brief
- **Female voiceover** throughout (intro / each transition / outro) — `zf_xiaoyi`.
- **No ranking in the intro**; ranking listed only in the outro summary.
- Ranking (1→5, best→least): 1 《Take Me》, 2 《Orange Moon》, 3 《黑洞里》, 4 《暖》, 5 《Over》.
- TTS never pronounces the **English titles** (Take Me / Orange Moon / Over) — Kokoro misaki[zh] mangles CN-EN mixing. Voice describes those songs; the on-screen card carries the exact title. Voice may speak the Chinese titles (暖 / 黑洞里). Visual = title authority; audio = description.
- Pure-Chinese narration terms only (灵魂乐 / 节奏蓝调 / 律动 — never "Neo-Soul/R&B/groove" inside TTS text).

## Visual identity
- Mood: warm, intimate, connoisseur ("内行才懂") — this is a *gem* countdown, not a "hardest/danger" one.
- Background: real 方大同 live footage, letterboxed (single subject but cautious — many are wide stage shots), crop only burned UP主 logos / watermarks.
- Palette (warm amber, nodding to 《橙月》):
  - base `#0a0805`
  - panel/scrim `rgba(8,6,4,.70)`
  - text `#f7f1e8`
  - muted `#c3b6a4`
  - accent (gold) `#e9b35a`
  - rank-1 highlight = luminous orange `#ff9a3c` (a *crown-jewel* glow, NOT danger red).
- Type: Noto Serif SC (display), Noto Sans SC (UI). Heavy weights, no negative letter-spacing.
- Motion: clean slides + marker-line reveals; no decorative orbs.
