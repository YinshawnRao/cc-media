# 华晨宇最难的5首歌 — Design

## Format
- 竖屏 1080×1920, 30fps。倒数揭晓 5 → 1（开头不剧透完整榜单）。
- 女声旁白（zf_xiaoyi，brief 明确要求女声）贯穿：开头钩子 / 每首转场 / 结尾，全部女声。
- 每首结构：女声转场旁白 → 消化位/swell → 连续副歌展示（SHOW≈38s，含前后余量）。
- 结尾＝作品 outro（榜单总结+升华）→ 消化位 → 固定引流 CTA（硬约束，全片最后一句）。

## 排名（揭晓序 5→1）
- 05《烟火里的尘埃》— 安静比爆发更难唱稳（弱声/气息/真假声边缘）
- 04《我管你》— 摇滚爆发拼体能（声压/态度/稳定）
- 03《寒鸦少年》— 全程冷峻锋利不松劲（穿透力/咬字/持续向上）
- 02《斗牛》— 唱完像打完一场比赛（节奏密/推进猛/控制）
- 01《齐天》— 难度天花板（吟唱/说唱/高位爆发兼顾，孤傲→炸开）

## Visual Identity
- 基调：暗底、克制、声乐分析向、火星/戏剧张力。
- 背景：真实现场/MV footage，letterbox 保原比例（综艺直播台标/赞助/歌词全裁净）。
- 配色：base `#08070a`；text `#f8f3ec`；强调暖橙 `#e0913f`（华晨宇火星暖橙）；第1名危险红 `#ff6a5c`/`#c7333f`。
- 字体：系统 CJK 重字重；动效干净滑入，无装饰球/泡泡。

## Composition Rules
- 封面：标题 + premise + chips，footage 取齐天特写（暗场，与 outro 呼应）。
- 歌名卡：大号倒数序号 + 歌名 + 难点 tag/note；展示段只留左上小角标，让画面呼吸。
- 字幕只显示当前旁白意群；画面内不得出现水印/网址/提示词/项目内部词/meta。
- 最终榜单：1 齐天 / 2 斗牛 / 3 寒鸦少年 / 4 我管你 / 5 烟火里的尘埃。
