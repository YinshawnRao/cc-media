# 罗志祥最难的5首歌 — 选源与制作记录

倒数盘点 #5→#1。竖屏 1080×1920，男声 zm_yunxi。**全部用 YouTube 官方 MV**（B站对照后官方更干净）。

## Brief 事实纠错（旁白已据此改写）
- **5 首没有一首是罗志祥本人作曲/作词** → 旁白不说"他写的"。
- **《精舞门》= 2006《Speshow》(avex) 主打，不是 2008 同名电影主题曲**（电影陈小春/范冰冰主演，罗不在其中）→ 不提电影。
- **《舞极限》= 2012《舞极限 新歌+金选》(金牌大风) 新歌 + 2013 巡演主题曲**，非《舞所不在》。
- 《拼什么》《独一无二》= 2011《独一无二》(金牌大风)；拼什么是第一主打、他首支慢歌主打。
- 《不具名的悲伤》= 2012《有我在》(金牌大风)。

## 坑
- **YT 媒体 403** → `--extractor-args youtube:player_client=web_safari`（不是 tv），DASH 分片下载慢。
- 烧死卡拉OK歌词普遍（金牌大风年代）：精舞门(中/英 You gonna know)、舞极限(y950)、拼什么(在内容区底 y385-420，须 crop 到 320 不是 360)、不具名(底烧标题+词 y910-1070)。独一无二无烧词。
- **`TbfdPOd2u5s`（标 1080p 独一无二）是蓝底静态标题卡假 MV**，弃；独一无二官方上传全 480p。
- 两首慢歌(拼什么/不具名)是剧情片（张钧甯主演不具名），他正脸特写穿插剧情，展示窗落他特写密集段、保留 MV 原生剪辑（未另做蒙太奇）。
- **showcase_align 闸门**：full_build 的 blocks 必须带 `mseek` 键，否则 gate 误判全部 WARN。

## 设计 / 节奏
- 暗底 #06080d + 电光青 #4fd6f5 强调色（#1 用金 #ffd27a），dance/电子主题。
- 每首：转场旁白(音乐 duck ~-24dB) → 消化位/swell → 副歌展示(~-15dB, 22–26s)。
- intro 钩子短(先说结论/舞王的难不只是跳)；outro 收"快歌拼体能、慢歌拼真功夫"；固定 CTA 末句。
