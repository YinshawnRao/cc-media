### 关键选源说明
- **概念/剧情MV的局限**：#2《如果不是因为你》官方MV、#5《认错》优客李林官方MV 都是**剧情/概念片**，歌手演唱镜头很少甚至没有。按用户"官方MV优先"仍采用：#5 用年轻优客李林影像(切题"早期作品")，#2 收尾锁他的演唱特写。若需"全程看他唱"，可改官方Live（需另寻无烧字/台标干净源）。
- **letterbox 全宽保原比例**（硬规则）：所有 footage 全宽呈现、上下模糊背景填充，不竖裁放大（多机位/剧情/双人源尤其禁止竖裁）。clarity/画幅没源那么满属预期。
- **旁白逐字稿**见 `build/narrate_segments.py` / `narration.json`。

## 复现步骤
1. 重下源切片（上表 URL+时间码，需有效 cookie）。
2. 配音（女声）：`tools/tts/venv/bin/python build/narrate_segments.py` → `audio/*.wav` + `narration.json`。
3. 竖屏化+切窗（letterbox 一步到位）：按上表 crop/窗口跑 `ffmpeg ...crop+vfill`；封面单帧 zoom-crop 到 `hf/cover_assets/cover_bg.jpg`。
4. 合成+音频：`python build/full_build.py` → `index.html` + `master.wav`（逐段床→swell→展示 + 旁白 ducking + 逐首 loudnorm I=-14 + 整体 +3dB）。`LZX_SAMPLE=1` 出样片。
5. 渲染+mux（HyperFrames 压平音频动态→必须后期 mux；本机随机帧崩→重试循环）：
   ```
   npx hyperframes render --output renders/full_raw.mp4 --sdr -w <n>   # 崩则重试/降 -w1
   ffmpeg -i renders/full_raw.mp4 -i master.wav -map 0:v -map 1:a -c:v copy -c:a aac -b:a 192k -shortest renders/linzhixuan-hardest.mp4
   ```
