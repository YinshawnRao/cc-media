# 李健最难的5首歌 — Design

## Format

- Vertical short-form video, `1080x1920`, 30fps.
- Countdown order: 5 -> 1, per user brief.
- Female narration for opening, each song transition, and ending.
- Each song section: narration over ducked music -> breathing beat -> continuous showcase.
- Final spoken line is the fixed series CTA from `tools/video/outro_cta.py`.

## Visual Identity

- Mood: quiet, high-difficulty vocal analysis; restrained, poetic, precise.
- Background: real MV/live footage, letterboxed unless a crop is proven safe.
- Palette:
  - base: `#06080b`
  - deep panel: `rgba(5,8,12,.72)`
  - text: `#f5f7f2`
  - muted text: `#c3c9c0`
  - accent: `#8cc8d8`
  - rank-one accent: `#d8b56d`
- Type: system CJK stack; large readable text; no negative letter spacing.
- Motion: slow pressure-line reveals, breath-like drift, clean push/blur transitions.

## Composition Rules

- Cover shows title and premise only, not the full list.
- Song cards use rank, song name, and one compact difficulty tag.
- Showcase sections keep overlays small so the music footage can breathe.
- Avoid meta text such as "制作流程", "倒数开始", source names, URLs, or paths.
- If a source has burned lyrics or platform marks, crop/mask before delivery.
- Final summary order: 1 贝加尔湖畔, 2 假如爱有天意, 3 向往, 4 传奇, 5 美若黎明.
