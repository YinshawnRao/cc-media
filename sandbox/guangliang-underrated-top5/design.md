# 光良最被低估的5首歌 — Design

## Format
- 竖屏 1080×1920, 30fps. 倒数揭晓 **5 → 1**.
- 片头**不剧透排名**（封面 = 标题 + 作品描述 + chips，不列榜单）。片尾才揭晓完整排名。
- 每首：女声旁白（音乐床）→ swell → 连续副歌展示（~32s）。
- 女声 `zf_xiaoyi`（brief 明确要求开头/转场/结尾都女声）。

## Hard constraints from brief
- **女声旁白**全程（intro / 每首转场 / outro）。
- 片头不出现排名；排名只在片尾总结列出（5→1）。
- 排名（1→5，最被低估→次之）：1《如果你还爱我》 2《握你的手》 3《期限》 4《海边》 5《住在遥远的星球》。
- 盘点从第5名数到第1名（倒数揭晓）。
- 全片最后一句固定引流 CTA（见 CONVENTIONS「固定结尾配音」），作品 outro 不带投票问句（防双 CTA）。
- 所有歌名都是中文，TTS 可正常念。

## Visual identity
- 基调：温柔、内敛、文艺（光良情歌质感）；这是「遗珠」盘点，不是「最难/危险」盘点。
- 背景：光良本人演唱影像，letterbox 全宽保原比例，只裁烧词/水印横带。
- 配色（暖夜蓝紫，呼应光良抒情质感 + 《不会分离》《童话》色调）：
  - base `#0a0b12`
  - panel/scrim `rgba(8,9,16,.72)`
  - text `#f3f0ea`
  - muted `#bcb6c4`
  - accent（柔金）`#d8b06a`
  - rank-1 highlight = 暖光金 `#ffcf7a`（皇冠遗珠的光，不是危险红）。
- 字体：Noto Serif SC（display 歌名/标题），Noto Sans SC（UI）。重字重，不用负字距。
- 动效：干净滑入 + marker 线揭示；无装饰球。

- 2 握你的手：官方 2016「回忆里的疯狂」巡演 Live 同源 → 对口型。XXmusic 角标 delogo + 裁底词曲/烧词。
- 3 期限：录音室音频（官方频道）+ 2016 巡演《那些爱过的事》Live B-roll（解耦）。该曲是《童话》深专辑曲，全网无 MV/Live。
- 4 海边：录音室音频 + 2016 巡演《烟火》Live B-roll（解耦）。同为《童话》深曲，无 MV/Live。
- 5 住在遥远的星球：录音室音频 + 2016 巡演 Live B-roll（解耦）。官方上传是静态歌词视频；现场仅远景 fancam。
- 全片视觉主线 = 光良演唱中的本人影像，温柔内敛。
