# 林俊杰最被低估的5首歌 — Design

## Format
- 竖屏 1080×1920，30fps，约 5:17（317s）。
- 倒数 5→1。**开场不揭名次**（封面 = 标题 + 作品描述 + chips）；片尾列完整榜单。
- 每首：女声旁白（音乐床）→ 短 swell → 连续展示段（~32s）。
- 片尾：榜单升华旁白 → 消化位 1.0s → **固定引流 CTA（全片最后一句，逐字固定）** → 床末 1.6s fade。

## Brief 硬约束
- **女声**通篇（zf_xiaoyi）：开头 / 各转场 / 结尾。
- **开头不揭排名**；榜单只在片尾。
- 排名（1→5，最被低估在前的反倒数呈现）：1《距离》 2《不流泪的机场》 3《突然累了》 4《陌生老朋友》 5《黑键》。
- 全中文歌名 → TTS 照念（本期无中英混读问题）。
- 旁白歌曲描述参考 brief，打磨为口语、通顺、JJ 向；不照搬病句。

## Visual identity
- 基调：内行向「华语遗珠」盘点——温润、克制、有质感（不是「最难/危险」那种紧张感）。
- 背景：真实 JJ 影像（Live / 官方 MV），**letterbox 保原比例**，只裁烧词/台标横带，**不竖裁放大**（故事 MV 含双人/宽镜，竖裁会切人）。
- 配色（深蓝黑底 + 暖金，呼应 JJ 蓝台 + 早期暖色遗珠）：
  - base `#080a12`（蓝黑）
  - scrim `rgba(6,8,14,.70)`，text `#f4efe5`，muted `#d0c5b4`
  - accent（金）`#e7b15a`
  - rank-1 高亮 = 暖橙 `#ff9a3c`（冠军级暖光，非危险红）。
- 字体：Noto Serif SC（标题/歌名），Noto Sans SC（信息）。重字重，无负字距。
- 字号按 1080×1920 手机端基线放大（rank 31 / h2 90 / tag 43 / note 32 / mini 44）。
