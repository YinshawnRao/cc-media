# 罗志祥最被低估的5首歌 - Source Notes

制作原则：每首歌同时检查 YouTube 与 B站候选，优先官方 MV；若官方源为静态封面、画面水印无法避开或质量明显不适合成片，则选择更干净的动态画面源。所有最终画面均转为 1080x1920 竖屏，并通过抽帧检查避免出现平台水印、网址、路径或提示词。
