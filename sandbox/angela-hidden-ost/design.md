# 张韶涵隐藏OST名场面 — design.md

风格关键词：复古电视剧 OST 考古 · 老录像带 / CRT · 怀旧暖色 · 惊喜 · 温柔。
不要：粉丝尬吹、PPT 罗列、综艺花字、冷蓝高科技感。

## 画幅 / 帧率
1080×1920 竖屏 · 30fps · H.264 SDR（render 必加 `--sdr`）。

## 配色（暖怀旧，低饱和）
- 底：`#120D0A`（暖黑）/ `#1A1310`。
- 纸张暖白主文字：`#F2E6D2`。
- 强调金（标题卡/序号/关键词）：`#D9A martial`→ 用 `#D8A55A`（旧电视暖金）。
- 次强调暖红（情绪点）：`#C2563B`（录像带红）。
- 弱化米灰：`rgba(242,230,210,.55)`。

## 字体
- 中文衬线主标（歌名/标题）：`Noto Serif SC`（700/800）——怀旧、有质感。
- 中文无衬线 UI（序号/小字/关键词）：`Noto Sans SC`（500/700/800）。
- 西文/年份/「OST」标记 mono：`JetBrains Mono`（500/700）——做"档案编号/电视播出时间码"感。

## 复古视觉效果（CSS 叠层，确定性，不放过画面/字可读）
1. **扫描线 scanline**：`repeating-linear-gradient` 1px 暗线 / 2px 透明，整体 opacity ~.10。
2. **胶片颗粒 grain**：多点 radial-gradient 纹理，opacity ~.5，`mix-blend-mode: overlay`。
3. **暖色低饱和滤镜**：footage 烘焙 `eq=saturation=0.82:contrast=1.06:brightness=0.02` + 轻微暖 curves + vignette；CSS 再叠暖色 `multiply` 低 alpha 层。
4. **CRT 暗角 vignette**：径向暗角，四角压暗，模拟显像管。
5. **转场**：老电视"关机白线收束/开机"、录像带横向 roll、片尾字幕滚动、剧集画面定格泛白。**不要**炫光快切。
6. 颗粒/扫描线 opacity 必须低到**不影响人物脸和文字可读**（brief 硬要求）。

## footage 呈现
- **全宽 letterbox 保原比例**（不竖裁放大，避免切脸；双人/宽景安全）。上下用模糊同源背景填充。
- **保留电视台台标 / 烧入的歌名词曲 credit / 剧情字幕**——它们是"这首歌=这部剧 OST"的**绑定证据**，是本片主题核心，不是要清除的水印（与一般片不同；平台/UP主水印仍要裁）。
- SD 源（不痛 320×240 / 真的 640×480）：靠扫描线+颗粒+暖色做旧，"软"读作老录像带质感。若全屏太糊，退化为"居中 CRT 屏"缩小呈现（减小放大倍数）。

## 每首结构（brief）
标题卡（歌名 /《剧名》/ 原来它也是OST）→ 剧画面引入 → 解说（音乐 duck，女声温柔怀旧）→ **完整副歌展示**（解说停、音乐满）→ 情绪转场。
- 单首展示段 ≥ ~28s 连续副歌（brief：不为时长截断副歌）。
- 字幕：**不做整句烧字幕**，用标题卡 + 每首 3 个"关键词标签"（brief 的"画面字幕关键词"）+ 可选 1 句中段金句。清晰复古、不花。

## 封面（首帧即缩略图，不得 fade-in 黑屏）
- 中心：张韶涵**早期清晰正脸**（`cover_assets/zsh_face.jpg`，源自隐形的翅膀 MV era 正脸）做圆/方暖框。
- 周围：**模糊处理的电视剧画面碎片**（几块剧集截图 blur）做底，暖色压暗。
- 文案 ≤ 两行：第一行「张韶涵」/ 第二行「隐藏OST名场面」。角标小字「这些歌你可能听过，但未必知道出处」。
- **不写歌单、不列 5 首歌名 / 剧名**（保留悬念，brief 硬要求）。

## 配音（brief：女性、温柔、怀旧、轻微感叹，不煽情不尬喊）
- `zf_xiaoyi`（女声）。语速 ~1.0。重点词稍停顿。
- 口播 "OST" 念不好 → 口播用「主题曲 / 影视歌曲 / 剧歌」替代，**屏幕文字保留 OST**。

## 音频（brief：原曲为主，不叠强 BGM；解说时降音乐、副歌时停解说）
- 每首：歌曲录音室音频连续铺底 → 解说段 duck 到 ~22% → 副歌段恢复满量、解说停。
- 跨首 `loudnorm I=-14`，副歌均落 ~-15dB。
- 副歌进入前可加轻微"电视噪声/环境音"转场，但不压听歌。
- 片尾：作品 outro（升华，不自带投票问句）→ 固定引流 CTA（女声，逐字，全片最后一句）。

## 结构（全片，叙事序非倒数）
封面 → 开头悬念 → 5 首（1 不痛/你来自哪颗星 · 2 白白的/贝多芬病毒 · 3 真的/红拂女 · 4 其实很爱你/屋顶上的绿宝石 · 5 隐形的翅膀/爱杀17）→ 5 部剧快速闪回 → 作品 outro → 固定 CTA。
> 样片只做：封面 + 开头悬念 + 第 1 首《不痛》整段。
