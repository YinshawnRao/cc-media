# design.md — 《顾里之前，她明明是甜妹啊。》

竖屏 1080×1920｜女声盘点｜倒数 5→1｜复古甜妹 × 早期华语流行 × 偶像剧记忆

## 一句话基调
不是暗黑高级风（那是过往项目），而是**胶片暖调 + 糖果点缀 + 千禧偶像剧记忆**。
甜来自**配色 / 颗粒 / 柔光**，不来自廉价可爱字体——保持「高级但温柔」。

## 全局视觉
- **底色**：奶油暖白 / 暖米 `#FBF3E7`，叠 **胶片颗粒 grain + 轻微 halation 柔光 + 暗角 vignette**，做千禧 MV / 偶像剧质感。**不是纯黑底**。
- **文字**：暖奶油 `#FFF6EC` / 深可可 `#3A2B26`（亮底上用深色字）。**不用纯白**。
- **强调**：糖果色系，按每首切换（见下）。整体偏暖；只有 No.2《爱异想》起带一点「顾里冷感」做反差铺垫。
- **顾里冷感对照色**（封面左 + 开头反差 + 转场点缀）：钢灰 `#2B2F3A` + 唇红 `#D6435A` + 冷调去饱和。
- **禁止**：霓虹 / 紫 / 赛博风；廉价卡通字体；过曝白脸帧；任何水印/网址/路径/项目内部词。

## 字体（HyperFrames 自动 fetch Google Fonts）
- 标题 / 歌名（暖衬线，复古）：**Noto Serif SC** 700/800
- UI / 标签 / 排名数字 / 年份（圆润无衬线）：**Noto Sans SC** 500/700/800
- 装饰强调（封面英文 / 反差短语，手写感，少量）：**Ma Shan Zheng**（仅封面/转场点睛，不滥用）
- 字号基线遵守 CONVENTIONS「长篇片字号基线」（rail-tick 22+，card 辅助 28+，竖屏放大一倍）

| 序 | 歌 | 情绪 | 主强调色 pri | 辅 acc | 颗粒/点缀 |

| No.3 | 卡通人生 | 鬼马·漫画·可爱暴击 | 糖果粉 `#F4A9C0` | 漫画彩(星星/爱心) | 贴纸/星星/分镜框（克制，不廉价） |

## 封面（第 0 帧即缩略图，硬约束）
- **左右分屏 + 斜切缝**：
  - 左 = **顾里印象**：郭采洁本人短发/红唇/冷脸帧，去饱和→近黑白灰 + 钢灰底 + 唇红点；都市冷感。
  - 右 = **早期甜妹**：郭采洁本人早期长发/清新帧，暖胶片 + 糖果渐变 + 颗粒 + 阳光。
- **大标题**：《顾里之前，她明明是甜妹啊。》Noto Serif SC 超大，清晰压在画面（不拥挤）。
- **中缝反差钩子**：「这真的是同一个郭采洁？」（Ma Shan Zheng 手写感或衬线，醒目）。
- **不泄漏**：封面不出现 5 首歌名、不出现完整排名。
- 真人硬约束：两侧都必须是**郭采洁本人**（不用演员替身/标题党直拍）。

## 开头（0–10s）
- 前 10s **不泄漏歌名/排名**。先建立反差悬念：冷顾里镜头 ↔ 早期甜镜头快速并置（左右滑切 / 黑白→上色），叠开场旁白钩子。
- 只强调主题，不展示榜单。

## 转场（每首之间，反差短句）
4 句反差转场（brief 给定），融进**下一首旁白开头** + 转场卡短闪文字（crossfade 1s 重叠，防黑场）：
1. 5→4：还没到顾里的冷脸时期，她已经开始有一点小倔强。
2. 4→3：甜妹不一定只会撒娇，也可以很鬼马。
3. 3→2：你以为她后来才有气场？其实早期的甜里已经有一点锋利。
4. 2→1：最后这首，才是本期真正的小太阳。

## 每首在屏包装
左侧倒数轨（No.5…No.1 高亮当前）+ 右上玻璃歌名卡：
`No.X` · 年份/专辑 · 《歌名》· 词曲/演唱 · 一句甜感短评 tag。
副歌段落淡出卡片、起大字关键词 + 中段金句（见 narration.md）。

## 节奏与音频（遵守 CONVENTIONS 硬规则）
- 每首**连续副歌 ≥ ~25s**（No.1 finale 最长），footage 窗 == 音乐窗，口型同步；不碎镜快闪。
- 介绍旁白期音乐压低做床（ducking），副歌无旁白音乐全量；旁白收尾留 0.8–1.2s 消化位。
- 全片逐首 `loudnorm=I=-14`，副歌 ~-15dB 一致；渲染后**后期 mux master.wav**。
- 竖屏默认 **letterbox 保原比例**；双人/宽机位禁裁放大。

## 渲染
- `npx hyperframes render --sdr`，本机 GPU 截帧随机崩 → **`-w1` + 重试循环**直到产物时长达标。
- 总时长目标控制在合理范围（>240s 会关 streaming-encode，更易 OOM，靠 -w1 兜）。
