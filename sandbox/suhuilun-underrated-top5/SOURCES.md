## 核心选源现实（重要）

苏慧伦 90s 在**滚石唱片**。逐一抽帧 + 查格式核实：

- **你来 / 哭过的天空 / 你有离开的自由** = 滚石官方频道（滾石唱片 ROCK RECORDS）有**真官方 MV**，618×480 SD 30fps，底部带卡拉OK烧词。
  → **耦合**：footage 从源 `mseek` 切，与本曲音轨（从同一 MV 提取）同源同窗 → 副歌口型同步。
- **酿爱 / 叶子落下的世界** = 非单曲，官方频道（蘇慧倫 TarcySu）只有 **480×480 方画幅 + 极低码率（47k/98k）= 静态专辑图 + 音轨**，不是真 MV。
  → **解耦**（与 memory `xuruyun-underrated` / `zhangyusheng-underrated` 同款）：录音室音轨用静态版的干净音频，画面用苏慧伦本人**其他真官方 MV** 救场。
