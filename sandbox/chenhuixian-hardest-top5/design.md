# design — 陈慧娴最难的5首歌

竖屏 1080×1920，倒数 #5→#1（#1=月亮 压轴）。基调贴合陈慧娴这几首歌的「清冷、克制、优雅」。

## 视觉
- **底色**：极暗墨蓝 `#080a0f`，全程暗调，footage 上压渐变 scrim 保证字幕可读。
- **强调色**：月光冷银蓝 `#a8c2ea`（eyebrow / 序号 / rank）；#1《月亮》用暖金 `#e8c977`（topRank 卡 + 榜单末行）。
- **字体**：标题/歌名衬线 `Songti SC`（古典、贴老歌质感）；正文无衬线 `PingFang SC`；序号/年份等宽 `JetBrains Mono`。
- **footage**：letterbox 保原比例（老 MV 标清 4:3 / 16:9 都全宽呈现、不放大），裁掉烧死卡拉OK歌词 + 台标横带。
- **封面**：千千阙歌 1989 正脸特写（最经典辨识），居中（防小红书 3:4 裁切），上中位留出标题区。

## 信息层级
- 转场期：大卡（第X名 + 专辑·年 + 歌名 + 一句难点 tag + 一句注解）。
- 展示期：卡淡出，仅左上角小角标（序号 + 歌名），不压住 MV。
- outro：最终榜单 5→1 + 主题升华；固定 CTA 浮层（点赞收藏关注）随末句亮起。

## 节奏 / 音频
- 每首：转场旁白（音乐 duck 成床 0.16）→ 消化位/swell → 副歌展示（音乐推满、无旁白，连续 ≥24s）。
- 副歌人声入点对齐旁白收尾（showcase_align 闸门强制），结尾落句末/器乐 gap 不切半句。
- 逐首 `loudnorm I=-14` 统一响度；master.wav 后期 mux（HF 会压平动态）。
- 固定结尾 CTA 永远最后一句（防双 CTA：outro 不带投票问句）。
