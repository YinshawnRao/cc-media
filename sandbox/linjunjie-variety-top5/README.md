## 复现
1. cookie：`sandbox/www.youtube.com_cookies.txt` / `sandbox/www.bilibili.com_cookies.txt`。B站搜索 `tools/video/bili_search.py`。
2. 下源（见上表）→ `build/transcode.sh` 转 h264 密集关键帧到 `raw_h264/` + 抽全长 wav 到 `raw/`（输出端全解码避免 opus 截断）。封面肖像从 `raw_h264/s1.mp4` t=206 crop 到 `raw/jj_face.jpg`。
3. 配音（女声 zf_xiaoyi）：`tools/tts/venv/bin/python build/narrate_segments.py` → `audio/*.wav` + `narration.json`。
4. 合成+音频：`tools/tts/venv/bin/python build/full_build.py`（倒数序；每首 chorus 对齐副歌；逐段 床→swell→副歌 + ducking + 逐首 loudnorm I=-14 → `master.wav`；生成 `hf/index.html`）。
5. 渲染+mux：`bash build/retry_render.sh`（GPU截帧随机崩，-w1 重试 + --sdr）→ `bash build/finish.sh`（mux + QA 抽帧）。
