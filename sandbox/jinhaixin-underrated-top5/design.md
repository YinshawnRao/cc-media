# 金海心最被低估的5首歌 — design

## Visual Register

老 MV 档案感 + 透明女声的空气感。整体不是综艺花字，而是暗底、胶片、海面反光和戒指金属光混在一起的质感：安静、明亮、有一点童话式自由。

## Palette

| Token | Hex | Use |
| --- | --- | --- |
| ink | `#07090B` | base background |
| deep-sea | `#102E35` | cool shadows / background glow |
| pearl | `#F4EFE4` | primary text |
| mist | `#B8C9C7` | secondary text |
| ring-gold | `#D8AF5F` | ranking / emphasis |
| coral | `#D96D63` | rank 01 accent |
| glass | `#141A1E` | translucent panels |

## Typography

- Main title and song names: `Noto Serif SC`, 700-900.
- UI labels and notes: `Noto Sans SC`, 500-800.
- Rank numbers: `JetBrains Mono`, 700-800.

## Motion

- Primary rhythm: cover drift -> five calm reveal beats -> warm outro.
- Transitions: soft blur / film-light feel, no hard jump cuts.
- Image treatment: footage remains letterboxed, with blurred color-matched background and slow overlay motion.

## Rules

- Opening does not reveal all five songs.
- Ranking reveal order is 05 -> 01.
- Every song keeps a continuous full-music showcase segment.
- No platform watermarks, paths, URLs, prompt text, or source metadata in final frames.
