## 核心选源现实（重要）

杨乃文的"官方 MV"多为非演出形态，逐一抽帧核实：

- **如今 / 越美丽越看不见 / 在爱和你之间**：官方频道整张《越美丽越看不见》的"MV"是**统一的字体设计视觉**（霓虹绿+橙色双色调静态脸+滚动歌词），不是真演出 MV → 弃，**解耦**。
- **不要来找我**：官方频道上传是**近静态专辑图（"silence"字样）+ 音频**，几帧循环 → 不是真 MV → **解耦**。
- **路痴**：有真官方 MV，但是**叙事概念片**（城市 b-roll + 男主角 @233s + 反射镜头），歌手本人特写极稀疏 → 改用 **2024 路痴 Live**（红衣，连续单镜，干净）。
- **未接来电**：**真官方 MV**（暖调，本人特写 + 电话/光斑 b-roll，无他人）→ 耦合保留。
- **我给的爱**：有真官方 MV（1999 暗调叙事片），但**烧死卡拉OK歌词位置不固定**（宽镜中左 y≈240 / 特写底部）+ 浴室/水景 b-roll 多 → 弃 MV 画面，**解耦**用同期 Live。

**救场方案**：3 首解耦（官方录音室音轨 + 本人现场/Live 画面）。其中两首《Silence》姊妹作（#1 #2，旁白显式点明同专辑/同张震岳）统一用 **2001《Back To Music》演唱会**两个不同段落（#1 用红光高能 belting 段、#2 用蓝光柔和段），与"同一时期"叙事自洽。
