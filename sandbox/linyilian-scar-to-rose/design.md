## 调色板
- 底色：`#06070C`（夜墨蓝黑），次底 `#0C0E16`
- 文字主：`#ECE6DA`（暖灰白）、次 `#A9A39A`（灰）
- 强调金：`#D2A86A`（旧唱片暖金，用于序号/年份/装饰线）
- 强调红：`#A33141` / 高饱 `#C8324A`（玫瑰红，用于 tag / 主题红 / finale）
- 不用纯白纯黑大色块；所有面用低透明玻璃 + 细描边 + 暗角 vignette + 轻 film grain。

- 数字 / 序号 / 年份 / tag：`JetBrains Mono`

## 字号基线（竖屏，手机端放大一倍）
- 左侧时间线：圆点 48px、序号 22px/800
- 歌名玻璃卡（右上）：宽 640，card-no 36/800、card-year 24、card-name 78 serif、card-credit 28/500、card-tag 30/700(红)
- 旁白字幕：底部居中，44–48px/500，行宽≤18 字，2 行内；半透明暗条托底
- 屏幕大字（主题句）：56–72px serif，居中偏下，最多 2 短行

## 全片视觉母题（CSS 层，确定性、无随机）
- film grain（静态 SVG turbulence 叠 soft-light，低透明）
- vignette（radial 暗角）
- 细金色 hairline 装饰线（章节起手扫入）
- 红玫瑰 / 旧 CD / 歌词纸：以 footage 暗化背景 + CSS 几何/线条点缀为主，不堆低质 stock
- footage 一律 letterbox 保原比例（多为 4:3/合唱/双人源）；缓慢 ken-burns（scale 1.0→1.04）

## 结构（每首七阶段，沿用 lirh 时间线模板）
进入(LEAD) → 旁白(音乐床) → 消化位(POST_VOICE) → swell → 副歌展示(连续≥28s,finale~50s) → 转场金句叠副歌余韵 → 切下一首。
- 旁白期音乐 duck 到 ~20–25%；副歌展示无旁白、音乐全量。
- 章节交界铺低音乐床防死静；outro 床取副歌段末 1.6s fade。
- **固定结尾 CTA** 排在作品 outro 之后，逐字照念（硬约束）。作品 outro 不自带投票问句（防双 CTA）。
