# 动力火车最难的5首歌 — Design

## Format
- 竖屏短视频 `1080x1920`, 30fps，女声旁白（`zf_xiaoyi`）。
- 倒数揭晓 5 -> 1。**片头只给封面 + 作品描述，不剧透排名**；片尾才一次性列出完整榜单。
- 每首结构：女声介绍旁白（低音乐床）-> 0.8–1.5s 消化位（swell）-> 连续副歌展示（满量、无旁白）。
- 总时长 ≈ 5:16（intro 15s + 5 首 + outro/CTA 31s）。

## 双人组合硬约束
- 动力火车 = 尤秋兴 + 颜志琳（双人）。footage **一律 letterbox 保原比例**（全宽呈现 + 上下模糊填充），**禁止竖裁放大**（会把两人之一裁出画）。
- 展示段优先**双人真唱画面**；官方 MV 若是概念/剧情片（背叛科幻走廊、除了爱你概念片、彩虹橄榄球剧情）则改干净 Live。

## Visual Identity
- 基调：高压声乐解析，摇滚、克制、有张力。
- 背景：真实 MV / Live footage，letterbox。
- 调色：base `#08070a`；panel `rgba(5,5,8,.7)`；text `#f8f3ec`；muted `#cec4b8`；accent **暖琥珀 `#e0a23c`**（区别于那英期金色，更贴摇滚火车气质）；第一名危险色 `#c7333f`/`#ff727d`。
- 字体：系统 CJK 重黑体，无负字距。
- 动效：干净滑入、压感线条 reveal、轻颗粒，无装饰球/blob。

## Composition Rules
- 封面：标题 + 作品描述 + 5 个能力 chip（双人和声/持续高压/嘶吼亮度/长气息/尾段体能），**不列五首歌名**。
- 歌曲卡：大号倒数序号 + 歌名 + 一句难点 tag + 一句 note；展示段切到只剩左上角小序号标，让 footage 呼吸。
- 烧词/水印源：合成期靠 footage **crop 去污染带**（全宽横带），不足时才加底部遮罩。本片 5 首均已 crop 干净，无需遮罩。
- 字幕/标签只显示当前旁白意思，**不出现任何项目内部/meta 文案、平台水印、网址、路径**。
- 片尾固定 CTA（全系列统一，逐字照念，排在作品 outro 之后）：见 `tools/video/outro_cta.py`。
- 最终榜单（片尾）：01 明天的明天的明天 / 02 彩虹 / 03 无情的情书 / 04 背叛情歌 / 05 除了爱你还能爱谁。
