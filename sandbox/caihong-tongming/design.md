# design.md — 华语同名歌曲盘点《彩虹》

竖屏 1080×1920 音乐盘点。主题：5 首同名《彩虹》、气质完全不同。要"同一个歌名、不同人生"的对比感，有悬念、有评论区讨论空间。

## 基调（硬约束）

- **暗底电影感**，不是儿童彩虹风。底色 `#06080F`（近黑蓝）。
- **彩虹 = 去饱和的电影光谱光带**（柔光、霓虹、低饱和），作为强调/分隔元素，绝不用高饱和原色块。
- 视觉母题（全期统一）：**雨后 / 光带 / 舞台追光 / 旧唱片磁带 / 歌词纸 / 彩虹色光影**。
- 怀旧但不老气；有音乐审美但不装深；有共鸣但不煽情过度。

## 字体

- 中文衬线主标：**Noto Serif SC**（700/800/900）
- 中文无衬线 UI / 标签：**Noto Sans SC**（500/700/800）
- 数字 / 年份 / Part 号 mono：**JetBrains Mono**（600/800）
- HF 编译期自动 fetch Google Fonts，无需本地 woff2。

## 字号基线（1080×1920，手机端能扫到）

- Part 卡歌名 78px，歌手/标签 30px，Part 号 36px letter-spacing .3em+
- 左侧进度轨节点圆点 48px、序号 22px 800
- 屏幕大文案（情绪铺垫句）48–56px
- 封面主标题 ~110–130px，副标题 44–48px

## 悬念铁律（brief 硬性）

- **封面不泄漏歌单 / 不列 5 位歌手 / 不排名**。封面只给：彩虹光带 + 黑唱片/磁带/歌词纸 + 居中放大的"彩虹"二字 + 主副标题。
- **开头 0–8s 不公布歌单**：快速蒙太奇（雨后街道 / 舞台灯光 / 旧 CD / 歌词字幕 / 彩虹光影）+ 旁白 + 两行屏幕文字。
- 进度轨在正片里可显示 Part 1–5 推进，但**封面与开头不出现**。

## 结构

封面(静帧可作缩略图) → 开头蒙太奇钩子(0–8s) → Part1…Part5（每首：情绪铺垫句 → 消化位 → swell → 连续副歌展示 ≥~25s，展示段压低旁白）→ 结尾回放 + 评论引导。

- **Part 2 双版本**：先梁静茹温柔段，**无缝转**五月天乐团副歌；用前后对照 +（转场处）短暂分屏/对照卡呈现"同一首歌两种失恋质感"。
- 展示段硬规则：连续整段 + letterbox 保原比例（双人/合唱/宽机位禁裁放大）；footage 窗 == 音乐窗。

## 成片铁律（仓库级）

- 渲染 `--sdr`；渲染后 **ffmpeg mux 预混 master.wav**（HF 压平动态）。
- 画面内**禁**水印 / 网址 / 路径 / 提示词 / 项目内部词 / meta 文案。
- 各首副歌响度 loudnorm I=-14 统一（~-15dB）；旁白段音乐明显压低；无 >1.5s 段内整片静音。
