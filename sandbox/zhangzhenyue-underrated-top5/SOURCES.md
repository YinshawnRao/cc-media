## 结构性取舍（逐首记录，重要）

- **#1 破吉他**：该《我是海雅谷慕》版有**比西里岸 PAW PAW 部落乐团**编曲。⚠️**初版踩坑**：用了 131-160 窗（部落吟唱+器吉他 bridge），`vocal_segments` 把部落合声/吟唱**误报成人声**（民谣+部落和声混淆检测，同 memory 里器乐误报坑），gate 假过(报100%)，**用户耳验"只有吉他声、完全没有唱歌的人声"**。修正：切几段候选 mp3 让用户耳定 → 用户选 **B 夜场段(75-95)**=张震岳抱破吉他对麦唱主歌。最终窗 **77-94.5**（他清唱两句主歌"…"+句末器乐收尾，本人+吉他在镜，收在唱完句后的器乐/海浪空镜不切半句），coverage 53% 诚实过 gate。**教训：民谣/部落编曲的人声检测不可靠，压轴必须导 mp3 给用户耳验，别信 vocal_segments 的"100%覆盖"。**
- **#2 路口**：叙事 MV（长发女主角剧情线 + 张震岳抱吉他穿插）。区段B(76-133) 张震岳在镜约90%，但内含 ~9s 器乐间奏（他弹吉他撑画面，贴"没有答案的停顿"主题）。climax 副歌(144-186)画面 ~95% 女主角 → 弃。选区段B。
- **#4 两手空空**：概念 MV（蓝光西装唱 + 豹纹部落舞群草原奇观快剪）。**无连续本人窗**。选 78-103（含全片最佳本人正脸 t77 蓝台西装唱主歌钩），是官方 MV 原生剪辑；**弃** finale 窗(188-219)（含黑猩猩玩偶 t214、豹纹舞群更跳）。
- **#5 梅雨季**：电影感夜景 2.35:1，全程烧中英双语字幕。选雨中坐钢琴弹唱 climax。作**动态封面源**（第一首出场）：intro footage 取自 vert_p5_meiyu 的 T0=170 起，与 #5 footage 帧首尾相接 → 封面切第一首画面不剪；封面第0帧=src170（暖光侧脸，轻提亮）。
