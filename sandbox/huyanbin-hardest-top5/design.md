# Design — 胡彦斌最难的5首歌

## Direction

- 竖屏 1080x1920。
- 气质：深色录音棚 + 现场舞台混合，偏音乐分析和成熟盘点，不做综艺花字。
- 节奏：倒数 5 -> 1。每首先用旁白讲难点，再把连续代表段推满，第一名用更强红色强调。
- 视觉关键词：呼吸、节奏格、歌词密度、舞台光束、唱作人手稿感。

## Palette

- Background: `#08070a`
- Panel: `rgba(8,7,10,.72)`
- Text: `#f8f3ee`
- Muted text: `#d1c8bd`
- Amber accent: `#d99a45`
- Red accent: `#d84b3f`
- Ink blue: `#182036`

## Type

- 中文以系统黑体为主，保证渲染可靠。
- 排名数字使用极粗字重，保持移动端快速可读。
- 歌名大字，难点短标签控制在两行以内。

## Motion

- 入口顺序：排名 -> 歌名 -> 难点标签 -> 说明。
- 音乐展示段保留小号排名条，不遮挡主体。
- 转场以暗场推入和光束扫过为主，避免硬切感。

## Avoid

- 不出现平台水印、网址、路径、提示词、UP 主 ID。
- 不激进竖裁导致人物只剩半边。
- 不使用单一紫蓝渐变或廉价花字。
