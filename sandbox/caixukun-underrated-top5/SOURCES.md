## 关键背景：蔡徐坤官方 MV 多为「非演出形态」

brief 要求「尽量官方 MV」。但抽帧核验发现，蔡徐坤的官方 MV 多是**动画 / 抽象 / 静态艺术片 / visualizer**，并不展示他本人演唱：

- **《Home》官方 MV** = 插画动画公益片（无真人；钢琴+童声，主题极契合）。
- **《没有意外》官方 MV**（蔡徐坤官方专属频道 `BYWkIVpsH-s` / 華研國際 `jwenUm03S_g`，均 310s）= 抽象/水墨动画，**无真人出镜**。
- **《RIDE OR DIE》官方方形 MV**（`l03X52RHGFA`）= 黑白艺术片，全程**同一「手捂脸」静态姿势**、几乎无运动、还遮脸 → 做动态展示段不可用。
- **《Hug me》官方 video**（`m_vUUvLwBME`）= 静态红调 visualizer + 烧死「HUG ME」标题 → 不能做动态展示。
- **《感受她》官方 MV** = 港风电影叙事片（含女主），他出镜镜头分散；官方干净版仅 360p，1080p 全是带水印搬运。

按用户「**质量第一**」与本仓库展示段硬规则（展示段必须看得到本人唱、连续 ≥~25s），最终走**混合选源**：Home 用官方动画 MV（最契合且本就是动态），其余四首改用**能看到他演唱的干净现场 / 巡演**。仅 #1 是纯官方 MV。已在成片汇报里如实说明，用户可要求换回。
