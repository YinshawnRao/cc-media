# 徐佳莹最难的5首歌 — Design

## Format

- Vertical short-form video, `1080x1920`, 30fps.
- Countdown order: 5 -> 1.
- Opening must not reveal the ranking list.
- Each song section: female narration -> short breathing beat -> continuous chorus/showcase.
- Ending can reveal the full ranking summary.

## Visual Identity

- Mood: restrained, high-pressure, vocal-analysis oriented.
- Background: real MV/live footage, letterboxed unless a crop is proven safe.
- Palette:
  - base: `#07070a`
  - panel/scrim: `rgba(5,5,8,.68)`
  - text: `#f7f4f0`
  - muted text: `#b7b0aa`
  - accent: `#e7b96a`
  - danger accent for rank 1: `#ef4d5a`
- Type: system CJK stack, heavy display weights, no negative letter spacing.
- Motion: clean slides, marker-line reveals, no decorative blobs/orbs.

## Composition Rules

- Cover: title + premise only, no list of five songs.
- Song cards use large countdown number and song title, but do not over-cover the singer.
- Showcase sections keep only a small top-left rank tag so the music footage can breathe.
- Captions show the current narration idea only; no internal production notes.
- Final summary lists: 1 极限, 2 身骑白马, 3 失落沙洲, 4 灰色, 5 到此为止.
