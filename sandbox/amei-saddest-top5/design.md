# 张惠妹最苦的5首歌 — Design

## Format
- 竖屏 1080×1920，30fps，约 4:40–5:10。
- 倒数盘点：第5名 → 第1名（揭晓顺序，盘点从最后一名往回数）。
- 开头**不公布**排名（封面 = 标题 + 作品描述，不列五首）；片尾揭晓完整榜单。
- 每首结构：女声解说（音乐低床）→ 消化位/swell → 连续副歌展示（原声全量、无旁白）。
- 配音：女声 `zf_xiaoyi`（Kokoro + misaki[zh]）。
- 片尾固定引流 CTA（全系列统一，逐字，最后一句）：作品 outro 升华 → 消化位 → CTA。

## Visual Identity（情绪天后 / 克制的痛）
- 基调：暗夜、克制、情绪向；不是综艺花字，是安静的、扛着的疼。阿妹的苦＝声音很有力量但把痛压住。
- 背景：阿妹本人现场/MV footage；默认 letterbox 保原比例；单主体稳定居中且不切人时才竖向放大。
- Palette（比梁静茹玫瑰更冷冽一点，配阿妹的力量感）：
  - base `#0a0710`（极深紫黑）
  - text `#f4eef2` / muted `#cabfca`
  - accent 绛玫 `#d6708a`（眉标、序号、卡左边、tag）
  - 强调 `#e88aa0` / `#f0a7b8`
  - rank-1 危机红 `#ff4d63 / #ff7384`
- Type：
  - 歌名 / 大标题：**Noto Serif SC** 700–900
  - 解说 / UI：**Noto Sans SC** 400–800
- Motion：干净位移/淡入，封面标题轻微 breathing；无装饰光球。首帧即可作缩略图（封面不 fade-in）。

## Composition Rules
- 封面：标题 + 作品描述，**不列五首歌名**；首帧 = 人质 4K 黑白正脸特写 letterbox 居中。
- 歌曲卡：大号「第 0X 名」+ 歌名(serif) + tag + note；展示段只留左上角小排名标签让画面呼吸。
- 字幕只表达当下解说意思；画面内无水印/网址/路径/项目内部词（连名带姓 delogo 右下、我恨我爱你 delogo 左上+裁底、剪爱裁底烧词）。
- 片尾榜单 1→5：人质 · 我恨我爱你 · 剪爱 · 掉了 · 连名带姓。

## 节奏 / 时长
- 展示段（连续副歌）：第5–2名 ≈ 32–34s，第1名《人质》压轴 ≈ 40s。
- 解说约 14–16s/首；解说期音乐低床，副歌展示全量、无旁白。
- 跨首响度统一：逐首 loudnorm I=-14，目标副歌均值 ~-15dB。
