## 核心选源现实（重要）

这 5 首都是冷门专辑曲，**没有任何一首有真人演出 MV**。各平台"官方"版本全是：
- **滾石 / ComixRockRecords「官方完整版 Comix」** = 动画/图形，无本人；
- **Timeless Music「Official Lyric Video」** = 歌词视频，无本人；
- **googlejerry / 滾石「Audio Video」** = 录音配静态专辑图/照片拼贴。

抽帧逐一证实（probe/he_gj, miaoxiao_rock, fengzheng_gj, meimei_gj, ziyou_gj 均为静图/动画）。
张雨生 1997 年车祸去世，这些深 cut 生前几乎没现场演过（《河》发行 3 周后即去世，无演唱会版）。

**救场方案（与 memory `wubai-underrated` / `linyilian-underrated` 同款，已验证优于多机位 Live）**：
**解耦** = 每首用本曲**干净录音室音频** + 画面取自**张雨生本人同期/同专辑官方 MV** 的真实演出/特写镜头（letterbox 保原比例）。每一帧都是他本人，按年代/造型分散到 5 支不同 MV，避免审美疲劳。

## 选源去重/分散（diversify）

5 支不同 MV，跨 1988/1992/1994/1995/1997 五个年代/造型：
- 我期待(94 海边乐队)、大海(92 金色海)、口是心非(97 草地暖调)、还是朋友(95 长发演唱)、天天想你(88，本次未用作展示——见下)。
- **口是心非用于 #3 与 #1**，但取**不重叠的两段**（160–210 / 208–258），且中间隔着 #2（还是朋友），**不连号同源**。
- 《天天想你》(1988，渺小同专辑) 曾试作 #2 画面，但该 MV 是剧情片（女主角+小狗戏占多，张雨生本人仅零碎 ~14s，且 218s 后有「UFO GROUP 飞碟唱片」烧死台标）→ 放弃，#2 改用《还是朋友》演唱特写（质量优先，解耦不要求同年代）。
