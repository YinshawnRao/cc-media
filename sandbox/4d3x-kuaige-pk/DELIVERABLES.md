### 每段时长结构
- Cover 静帧 4.0s
- Hook 11.22s（intro 旁白 + 7 卡闪现）
- Rules 15.93s（规则解说 + 7 卡布局）
- 候选 01-06 各 47.4 / 45.7 / 46.5 / 47.0 / 45.8 / 46.0s
- 候选 07 finale 49.9s
- Outro 31.4s（总结 14.3s + 投票引导 10.1s + 停留）
- **总片长 6:30**

### 每首歌结构（七阶段）
进入(LEAD 0.15s) → 音乐床起 ramp (PRE 0.8s) → 主旁白 (13-15s, 音乐 -15dB) → 消化位 (POST 1.2s) → swell (1.5s) → 副歌展示 23-25s (100% 音乐 + 大字金句) → 投票刺激句 (mid 4-5s) → 章节淡出 (1s)

### 音轨处理
- **女声 TTS**：每段单独生成 wav (Kokoro + misaki[zh] zh_xiaoyi 24kHz)，按时间轴精确 adelay 排序，天然字幕同步。
- **每首歌响度归一化**：`loudnorm I=-14:TP=-1.0:LRA=11` 跨段统一。
- **配音 ducking**：旁白响时音乐降至 18%（约 -15dB），音乐床→swell→副歌满音量动态包络脚本化（`volume='<分段表达式>':eval=frame`）。
- **响度归一化压平规避**：HF 渲染会自动响度归一化压平动态，所以 master.wav 后期 mux 覆盖（成片以 mux 后版本为准）。

### 字幕与转场
- 字幕全程同步旁白单句（旁白段 voice 显示卡片描述+候选编号+3 关键词；副歌段大字金句；mid 段弹出投票刺激句弹幕样式）。
- 章节淡入 1.4s scale 1.06→1.0；章节淡出 1.0s + hard kill `tl.set(opacity:0)` 防 seek 残留。
- 候选编号 / 玻璃卡 / 3 胶囊关键词使用 backdrop-filter blur 28px 半透明叠层（不遮歌手特写）。
- 每首段使用 per-song 配色 multiply tint overlay + radial gradient particle 层。

### 渲染参数
```bash
npx hyperframes render --output renders/full_raw.mp4 --sdr
# --sdr 必加，防 HDR auto-detect 触发 HLG 10-bit H.265 输出（短视频平台不收）

ffmpeg -i renders/full_raw.mp4 -i master.wav \
  -map 0:v -map 1:a -c:v copy -c:a aac -b:a 192k -shortest \
  renders/4d3x-kuaige-pk.mp4
```

成片以 mux 后的 `renders/4d3x-kuaige-pk.mp4` 为准。
