# 潘玮柏最被低估的5首歌 — Design

## Format
- 竖屏 1080×1920, 30fps. 倒数揭晓 **5 → 1**.
- 片头**不剧透排名**（封面 = 标题 + 作品描述 + chips，不列榜单）。片尾才揭晓完整排名。
- 每首：女声旁白（音乐床）→ swell → 连续副歌展示（30–34s）。
- 女声 `zf_xiaoyi`（brief 明确要求开头/转场/结尾都女声）。
- 总时长 ≈ 5:14。

## Hard constraints from brief
- **女声旁白**全程（intro / 每首转场 / outro）。
- 片头不出现排名；排名只在片尾总结列出（5→1）。
- 排名（1→5，最被低估→次之）：1《街头诗人》 2《跟我走吧》 3《我们都怕痛》 4《机会》 5《寂屋出租》。
- 盘点从第5名数到第1名（倒数揭晓）。
- 全片最后一句固定引流 CTA（见 CONVENTIONS「固定结尾配音」），作品 outro 不带投票问句（防双 CTA）。
- 所有歌名都是中文，TTS 可正常念（旁白回避英文 token：不写 Will Power / MVP / UUU）。

## Visual identity
- 基调：都会、冷冽、嘻哈质感（潘玮柏 / 《反转地球》的银蓝未来感），但收在「遗珠回望」的克制温度上。
- 背景：潘玮柏本人 MV/演唱影像，letterbox 全宽保原比例，只裁烧词/水印横带。
- 配色（午夜霓虹，青蓝主调 + 暖金压轴）：
  - base `#0a0c14`
  - panel/scrim `rgba(10,11,18,.72)`
  - text `#f3f0ea`
  - accent（电光青）`#46c8d8`
  - rank-1 highlight = 暖金 `#ffcf7a / #ffd98c`（青蓝里唯一的暖光，teal&orange 对比，给压轴《街头诗人》打光）。
- 字体：Noto Serif SC（display 歌名/标题），Noto Sans SC（UI）。
- 动效：干净滑入 + marker 线揭示；无装饰球。
