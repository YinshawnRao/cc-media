# design.md — 陈伟把萧亚轩做成了Elva（竖屏长片 8→1）

风格关键词：Y2K · 千禧都市 · 冷感 · R&B/舞曲 · 时尚 · 夜色霓虹 · 银色金属(chrome) · 胶片颗粒 · 唱片工业感。
**不要复古怀旧甜美，也不要榜单综艺花字。** 主张：萧亚轩不是甜妹，一出道就是都市女声；陈伟是把这套声音系统做出来的人。
（区别于 [林夕×王菲] 的暗红文学/精神性风——那条是港风文学，这条是千禧都市工业感。）

## 画幅 / 帧率
- 1080×1920 竖屏，30fps，H.264 + AAC。render 必加 `--sdr`。
- 成片以 mux 后为准（HyperFrames 压平音频动态 → 后期 mux master.wav）。

## 配色（近黑蓝底 + 青/蓝紫霓虹 + 银色金属 + 暗红点缀）
- 底：`#06070d`（近黑略蓝）。
- 主文字：冷白 `#e8edf5` / `#eef2f8`；次要灰蓝 `#96a4be` / `#b4c0d6`。
- 霓虹强调（主）：青 `#2fd6e8`/`#5fe4f5`（glow），蓝紫 `#7b5cff`。二者为 Y2K 霓虹双色。
- 金属银 chrome：linear-gradient `#f4f8ff→#cdd6e6→#8c97ad→#e6ecf7→#9aa6bd`（text-clip 做镀铬字，用于番号/ELVA/标题强调）。
- 暖点缀（少用）：暗红 `#c0413f`/`#e06b6b`，只给一两个情绪词（如"是冷"），呼应"都市夜色暗红"。
- 全程压：胶片颗粒 + 扫描线(CRT) + 暗角 vignette + 霓虹径向微光。宁暗勿亮、冷调统一。

## 字体（Google Fonts，HF 自动 fetch）
- 中文主标 / 字幕 / 屏幕文字：**Noto Sans SC**（500/700/900）——都市、现代、无衬线（不用衬线，避免文学怀旧感）。
- 拉丁 / 数字 / 番号 / 资料标签 / credit：**Chakra Petch**（400-700，Y2K techno 等宽感），番号"08"、"ELVA"用其 700 + chrome 渐变。
- 数字/年份/专辑也走 Chakra Petch（统一工业感）。

## 画面语言
- **主体 footage（萧亚轩官方MV/Live）一律 letterbox**：缩到 1080 宽居中、保留原比例，上下模糊填充（带内）。**禁止竖裁放大**（双人/合唱/宽机位会切人）。只裁烧死歌词的横向窄带。
  - 千禧台版官方MV多为 4:3/480p 卡拉OK烧词 → crop 全宽横带去词（如《没有人》crop `648:300:0:0`），letterbox 后 1080×500 带，可看可接受（用户口径=严格官方优先，画质软可接受）。
  - footage 带上叠冷蓝薄层(soft-light)统一 Y2K 冷调。
- **氛围层（CSS，不额外占 video 元素，规避本机 ≥7 video 崩）**：CD/唱片转动(chrome conic-gradient)、混音台推子/EQ 条、扫描线、霓虹径向光、胶片颗粒、镀铬边框卡。
- 转场：慢叠化（cross-dissolve 0.7–1.6s）。**不快闪、不滑屏花字。**
- 复古字幕条：字幕放半透明金属描边条里（lower-third），区别于林夕项目的纯文字。

## 结构（全片 8→1，叙事递进，非综艺倒数花字）
每首：① 番号(chrome)+歌名 ② 资料卡(曲·陈伟 / 词 / 制作，1999-2006 专辑) ③ 静帧/空镜进入 ④ 旁白点评(音乐 duck) ⑤ 连续副歌展示 ≥25-30s(音乐全量、无旁白) ⑥ 主题转场句递进。
- 每首主题标签：08出道冷感 / 07都市想念 / 06潮湿R&B / 05未来感 / 04低音深情 / 03体面成熟 / 02舞曲人格 / 01自我宣言。

## 音频（硬规则）
- 先配音后进音乐；旁白期音乐压到床位（B≈0.30 ≈ -24dB，约 -10dB ducking），300ms 平滑；旁白收尾留 ~1.2s 消化位再 swell。
- 展示段音乐全量(F=1.0)、无旁白，连续副歌 ≥25-30s；footage 窗==音乐窗(同源同窗)→口型同步。
- 各首副歌响度统一 loudnorm I=-14（落 ~-15dB）。
- **零容忍背景白噪音**：不用全片 ambient pad；段间用对应歌曲极低音量做床/桥接，或接受 <1.5s 自然短静音。
