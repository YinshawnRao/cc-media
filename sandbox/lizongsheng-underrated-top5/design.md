# 李宗盛最被低估的5首歌 — Design

## Format
- 竖屏 1080×1920, 30fps. 倒数揭晓 **5 → 1**.
- 片头**不剧透排名**（封面 = 标题 + 作品描述 + chips，不列榜单）。片尾才揭晓完整排名。
- 每首：女声旁白（音乐床）→ swell → 连续副歌展示（21–27s，李宗盛本人现场特写）。
- 女声 `zf_xiaoyi`（brief 明确要求开头/转场/结尾都女声）。
- 全片 ≈ 4:41。

## Hard constraints from brief
- **女声旁白**全程（intro / 每首转场 / outro）。
- 片头不出现排名；排名只在片尾总结列出（5→1）。
- 排名（1→5，最被低估→次之）：1《和自己赛跑的人》 2《你像个孩子》 3《远行》 4《希望》 5《一个人》。
- 盘点从第5名数到第1名（倒数揭晓）。
- 歌曲描述灵活参考 brief，文案打磨成口语化通顺旁白（非照搬）。
- 全片最后一句固定引流 CTA（见 CONVENTIONS「固定结尾配音」），作品 outro 不带投票问句（防双 CTA）。
- 所有歌名都是中文，TTS 可正常念。

## Visual identity
- 基调：温柔、内敛、文艺（李宗盛「人生叙事」质感）；这是「遗珠」盘点，不是「最难/危险」盘点。
- 背景：李宗盛本人现场演唱影像，letterbox 全宽保原比例，只裁烧词/水印横带（**禁止竖裁放大**，多机位 Live 会切到全景/乐队/侧背）。
- 配色（暖夜蓝紫，呼应李宗盛抒情质感）：
  - base `#0a0b12`；panel/scrim `rgba(8,9,16,.72)`；text `#f3f0ea`；muted `#bcb6c4`
  - accent（柔金）`#d8b06a`；rank-1 highlight = 暖光金 `#ffcf7a`（皇冠遗珠的光，不是危险红）。
- 字体：Noto Serif SC（display 歌名/标题），Noto Sans SC（UI）。
- 动效：干净滑入；无装饰球。

## 选源逻辑（详见 SOURCES.md）
- 五首均为 1986/1993 深专辑曲，全网**无棚版 MV**；统一用李宗盛**本人真实演唱会画面**（理性与感性2006 / 既然青春留不住2016 / 有歌之年2026），自带现场音轨 → **同源同窗、口型同步**。
