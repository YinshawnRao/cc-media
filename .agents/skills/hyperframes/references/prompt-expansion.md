# Optional internal prompt expansion

For a complex brief, a concise production note can record the narrative angle, scenes, timing dependencies, media needs and unresolved facts. Reuse design.md, timeline or manifest rather than maintaining a duplicate full specification.

Skip expansion for detailed briefs, straightforward work or small edits. Do not invent content, extra elements or choreography quotas to fill a template. Notes are internal preparation under the existing production authorization; no automatic approval stop. Ask only for required missing input or the review stage the user explicitly requested.
