# Optional style ideas

Use a project design spec when available; otherwise choose a visual direction that serves the content. Light, dark, solid, textured, sparse and layered designs are all available. Palettes and visual-styles.md are examples, not a closed set.

State a few useful design decisions, then build. Do not require a font discovery script, a banned-default checklist, fixed decoration counts or an extra user approval. Evaluate readable hierarchy, topic fit, subject visibility and motion pace in the actual output.
