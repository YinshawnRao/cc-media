# Voice and timing in cc-media

Use the central [Qwen workflow](../../../../tools/tts/README.md). The registered project selection is shared across narration; no provider picker or automatic engine fallback. Narration is optional only when the brief/design and project contract declare it.

Use actual WAV durations to update the timeline. Existing authorization covers routine timing adjustments; ask only when changing a core brief requirement. Captions are added only when requested. ASR and final audio checks use the repository tools, not a second transcription stack.
